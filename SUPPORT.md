# Support

CareerPilot is a community project without guaranteed response times.

- Use GitHub Discussions for usage questions and ideas when enabled.
- Use the bug report template for reproducible defects.
- Use the feature request template for proposed enhancements.
- Use private vulnerability reporting for security concerns.

Before asking for help, check the README, existing issues, and API documentation at `/docs`. Remove API keys, resumes, email addresses, phone numbers, and other personal information from logs and examples.
