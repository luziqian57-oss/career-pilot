# Changelog

All notable changes to CareerPilot are documented here. The project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Planned

- Persistent resume and workflow records
- OCR for scanned PDF resumes
- Authentication and privacy deletion controls

## [0.2.0] - 2026-08-18

### Added

- PDF and DOCX resume upload and text extraction
- Upload-to-job-match endpoint
- File type, signature, size, archive, encryption, and empty-text validation
- Tests using generated PDF and DOCX documents

## [0.1.0] - 2026-08-18

### Added

- FastAPI backend and OpenAPI documentation
- Deterministic resume parser and job matching baseline
- LangGraph workflow skeleton
- Mock and OpenAI LLM provider abstraction
- PostgreSQL, Redis, Docker Compose, tests, and CI configuration
